# Visual schemas for diagrams and UI

These files describe how a visual object is shaped, not a particular drawing. A flow schema tells you which fields a process diagram must have; [resource-flow](/visuals/graphs/resource-flow) is one instance. Load a schema when you are generating or validating visual content, not when you are trying to understand a raid.

Diagram, flow, and decision-tree schemas cover process and branching. Relationship-graph schema covers nodes and edges. Spatial schema covers coordinates and regions. UI schema covers screens and elements. Pattern schema covers recurring visual motifs.

The parent [visuals](/visuals/) index is the tour. This folder is the type system for that tour.

## When to open this page

Open visual schemas when you are producing or checking machine-readable diagrams. If you want the populated graphs, go to [graphs](/visuals/graphs/). If you want the galactic coordinate system, go to [spatial](/visuals/spatial/).

- [Diagram schema](diagram-schema) -- Diagram structures
- [Flow schema](flow-schema) -- Process flows and workflows
- [Spatial schema](spatial-schema) -- Geometric and spatial data
- [UI schema](ui-schema) -- Screens and UI elements
- [Relationship graph](relationship-graph) -- Nodes, edges, relationship graphs
- [Decision tree](decision-tree) -- Branching decision structures
- [Pattern schema](pattern-schema) -- Visual patterns
