# Graphs of entities, resources, and systems

Graphs are the relationship layer of the visual corpus: what connects to what, and in which direction. They are not pretty pictures for a slide. They are structured descriptions an agent can walk when a prose page is too long and a schema is too flat.

Entity relationships are the noun map. Resource flow is the mine → refine → stake/spend path. System integration is how clients, chain, GRASS, and Guild Stack sit together. Gameplay-economics is where a raid, an agreement, and a guild token actually touch.

If you need the drawing rules rather than a populated graph, that is [visual schemas](/visuals/schemas/). If you need coordinates, that is [spatial](/visuals/spatial/).

## When to open this page

Open graphs when you are tracing a dependency (who can raid whom, where ore goes, which service indexes what). If you want a command, that is a skill. If you want a field list, that is [schemas](/schemas/).

- [Entity relationships](entity-relationships) -- Every entity type and how they connect
- [Resource flow](resource-flow) -- Extraction through consumption
- [System integration](system-integration) -- Clients, chain, GRASS, Guild Stack
- [Gameplay economics](gameplay-economics) -- Gameplay actions tied to economic objects
