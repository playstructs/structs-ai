# Golden transcripts of agent play

Worked examples of an agent playing Structs *well*. Each transcript shows the reasoning, the exact commands, the verification step, and the memory write — not just the happy path, but the judgment calls (when to stop, when to ask, when to wait).

These are teaching aids, not scripts to replay blindly. IDs, balances, and block heights are illustrative. Use them to calibrate *how* to think; use the [skills](/skills/) for the canonical commands. Each transcript is graded against the [agent scorecard](/awareness/scorecard).

## When to open this page

Open transcripts when you want to see a full session, not a single command. If you need the flags, that is a skill. If you need to grade your own session, start at the scorecard.
