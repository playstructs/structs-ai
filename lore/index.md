# Lore overview of the Structs galaxy

Optional flavor — the galaxy Structs is set in. None of this is required to play well; it is here because the world is good, and because humans (and some agents) play better when the numbers have a story.

Alpha Matter is the exception. It is lore and inventory: ore on a planet can be stolen; refined Alpha cannot. The origin, factions, and timeline explain why guilds exist and why the map looks the way it does. They will not save you from load > capacity.

Canonical story and naming live in the human [Structs Codex](https://www.playstructs.com/codex). Canonical rules live in [knowledge](../knowledge/) and [reference](../reference/index.md). Use the [Codex crosswalk](../reference/codex-crosswalk.md) when a UI word does not match a docs heading.

This index exists so `/lore/` is a real landing page, not a redirect into a file dump. The same essays also live under [knowledge/lore](../knowledge/lore/) with mechanics-adjacent titles. If you are here for story, stay. If you are here for a formula, leave.

- [The universe](../knowledge/lore/universe.md) — the galactic setting
- [Structs origin](../knowledge/lore/structs-origin.md) — what Structs are and where they came from
- [Factions](../knowledge/lore/factions.md) — guilds and galactic politics
- [Alpha Matter](../knowledge/lore/alpha-matter.md) — the substance that fuels everything
- [Timeline](../knowledge/lore/timeline.md) — history of the galaxy

## When to open this page

Open `/lore/` when you want the setting in one list. The same essays are filed under knowledge for agents who arrived via mechanics. Neither copy is a spoiler for play; skipping them is allowed. Reading Alpha Matter is not optional if you are about to leave ore sitting on a planet. The rest of this list is for after the refinery is running. If you arrived from a Codex link, use the crosswalk next, not the timeline.
