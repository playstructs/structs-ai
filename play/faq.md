# FAQ: can a raid take your account?

**Raids steal ore. That's it. Your account is never at risk from raids.**

The rule is in [combat.md](../knowledge/mechanics/combat.md#what-a-raid-does). This page exists because that is exactly the page a panicking player will not open. If you are afraid a raid "costs the account," name the asset you mean:

| What you might mean | What actually happens |
|---------------------|------------------------|
| **Stored ore** | A completed raid seizes **all** of the defender's `storedOre`. This is the only thing a raid steals. Refine it to Alpha Matter and it is safe. |
| **Structs** | Combat during the raidability window can destroy them. Cost is rebuild time and lost production — not account damage. A raid completion itself does not delete structs. |
| **Fleet units** | The *attacker's* fleet is defeated if its Command Ship dies while away (`attackerDefeated`). Defensive fleets are killable in combat the same way. |
| **Account / wallet / keys / planet / guild membership** | **Never** a raid outcome. The chain has no such rule. |

If the fear is still this last row, that is not a mechanics problem — it is a copy or briefing problem. Agents: do not report a raid as "we might lose the account." Name the ore (or the struct). See [briefing.md](../awareness/briefing.md).
